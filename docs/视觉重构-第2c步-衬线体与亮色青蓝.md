## 1. 字体：全部换衬线

### 1.1 为什么这次不像上一轮那样落成 SimSun

上一轮（第 2 步）加过中文衬线标题，被用户否掉：「不要用宋体，太诡异了」。原因是当时的衬线栈是
`Source Han Serif SC → Noto Serif SC → Songti SC → STSong → SimSun`，而**这台机器上前三者都没装**，
于是落到 `SimSun`（中易宋体）——它在大字号下发虚，且只有一档字重，浏览器只能机械加粗，非常难看。

这一轮先查了本机字体表（注册表 `HKLM\...\CurrentVersion\Fonts`），确认**已安装 `Noto Serif SC`**
（思源宋体的 Noto 版本，字重 200~900 齐全）。所以换成以它为首选的栈，SimSun 直接不进栈：

```css
--font-serif: 'Noto Serif SC','Source Han Serif SC','Noto Serif CJK SC','Songti SC','STSong','Noto Serif',serif;
```

末尾用 generic `serif` 收尾，保证任何平台「最后的兜底」都是衬线而不是无衬线。
另外给 `html,body` 加了 `font-synthesis-weight:none`，防止浏览器把衬线机械加粗出塑料感。

### 1.2 落到哪里

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| `html,body` | `var(--font-sans)` | `var(--font-serif)` |
| `--font-display`（页面标题/分区标题/Hero 标题/Markdown h1~h4） | `var(--font-sans)` | `var(--font-serif)` |
| 开屏 splash（`index.html` 内联） | `system-ui, PingFang SC, Microsoft YaHei, sans-serif` | 同一套衬线栈 |
| 代码块 / 编辑器 / 评论框 / 小说章节输入框 | 等宽或 `inherit` | **保持等宽 / 改回 `var(--font-sans)`**（挤在一起的等宽字符和表单控件套宋体没法看，这是有意不跟着变的） |

字距、字号、字重一律没动——用户上一轮明确认可过「改字体大小」那部分，这次只换字体族。

## 2. 配色：亮色青蓝、暗色保留天蓝

### 2.1 做法：新开一族「强调色」token

「天蓝色」在全站对应的就是 `--sky-blue: #5BA8D8`（亮色主题用它做描边、淡底、光晕、Hero 渐变首尾与蓝色光斑、
滚动条浅档、进度条、封面占位渐变、按钮聚焦环）。这一族在亮色下整体换青蓝，暗色下一律指回原值：

```css
/* :root —— 亮色 */
--accent: #4A9BB8; --accent-deep: #2A6577;   /* 青蓝·眼睛 及同色相深档 */
--accent-halo: #7cbcd3;
--accent-shadow-soft: rgba(74,155,184,.32); --accent-shadow: rgba(74,155,184,.38);
--accent-shadow-strong: rgba(74,155,184,.44); --accent-veil: rgba(74,155,184,0.12);
--sky-blue-soft: color-mix(in srgb,var(--accent) 55%,#fff);

/* [data-theme='dark'] —— 暗色，全部指回天空蓝，等于这一层完全没变 */
--accent:#5BA8D8; --accent-deep:#4A9BB8; --accent-halo:#6ec3ef;
--accent-shadow-soft:rgba(91,168,216,.35); --accent-shadow:rgba(91,168,216,.4);
--accent-shadow-strong:rgba(91,168,216,.45); --accent-veil:rgba(91,168,216,0.15);
```

关键点：**暗色主题下 `--accent` 就等价于原来的 `--sky-blue`**，所以文件里 136 处 `var(--sky-blue)`
描边/淡底引用根本不用改——它们本来就是「原样保留天蓝」的那一批。真正需要改的只有硬编码的九处光晕与两处渐变，
已全部换成 `var(--accent-*)`。这也是这次「只动亮色」能做得干净的原因。

### 2.2 具体落点

| 位置 | 改前（亮色） | 改后（亮色） | 暗色 |
| --- | --- | --- | --- |
| 9 处蓝色光晕阴影（`.nav-links a.active`、`.filter-chip.active`、`.guestbook-tab.active`、`.profile-avatar`、`.nav-avatar:hover`、`.intro-avatar`、`.nreader-start-btn:hover`、`.back-to-top`、头像取景蒙层） | `rgba(91,168,216,.3~.45)` | `var(--accent-shadow*)`＝青蓝 `rgba(74,155,184,·)` | 由暗色 token 指回原天空蓝光晕 |
| `--shadow-sm/--shadow` 的极淡描边 | `rgba(58,134,184,0.08/0.12)` | `var(--accent-veil)` | 暗色本来就是黑阴影，不受影响 |
| Hero 渐变首尾色标 | 天空蓝 20% → `#DEEEF7` | 强调色 20% → `#DBEBF1` | 暗色 Hero 用的是自己的深色渐变，未动 |
| Hero 蓝色光斑 `.hero::after` | `var(--sky-blue) 45%` | `var(--accent) 45%` | 指回天空蓝 |
| 滚动条 / 插画式空状态浅档 | `#a8d4ec`（天空蓝浅档） | `color-mix(in srgb,var(--accent) 55%,#fff)` | 自动变回天空蓝浅档 |
| 附件进度条渐变 | `#5BA8D8 → #4A9BB8` | `var(--accent) → var(--accent-deep)` | 同左（暗色下即天空蓝→青蓝） |
| 小说卡 / 阅读器占位封面 | `#4A9BB8 → #2A6577` | `var(--accent) → var(--accent-deep)` | 暗色那处留到第 4 步统一处理（现为 `#2A6577 → #4A9BB8`） |

### 2.3 没有动的

- 主按钮 `--grad-main`（亮色 `#35769B → #2A6386`）——它是承载白字的深蓝，不是「天蓝色」；
  在 `4.98:1 / 6.51:1` 的可读区间里，动了反而不安全。
- 链接/标题墨色 `--sky-blue-dark: #2E6E92`、`--sky-ink`、`--sky-fill`——同上，属于文字层。
- `--sky-blue` 本身保留为「开衫蓝」并继续被大量描边引用（暗色主题就是靠它保持天蓝）。
