# 视觉重构 · 第2h步：暗色下小标题一律白色

日期：2026-09-14　范围：**只改暗色主题**，亮色主题一个字没动

## 用户要求（原话）

> 暗色下能不能把小标题全部变成白色，要不然看不清楚

## 改了什么

暗色主题里「要读的小标题」原来都带颜色，压在深底上偏暗、跟正文的白字抢不过对比度。
本步把它们统一成纯白 `#fff`（**只加了一段暗色覆盖块**，亮色规则零改动）：

| 小标题 | 选择器 | 暗色原来 | 现在 | 实测对比度 |
| --- | --- | --- | --- | --- |
| 分区标题（首页各分类 / Bug 反馈页） | `.section-title` | 该分类同色系墨色：随笔粉 `#f0a395`、读后感蓝 `#6ec3ef`、小说蜜金 `#e8cfa8`、数学笔记青蓝 `#7fc4d8`、学习分享灰蓝 `#a9b4be` | `#fff` | 页面底 17.29:1 / 卡片 14.71:1 |
| 正文小标题 h1~h4 | `.markdown-body h1..h4` | `--sky-blue-dark` `#4ba7d6` | `#fff` | 同上 |
| 关于页小节标题 | `.about-content h2` | `--sky-blue-dark` | `#fff` | 同上 |
| 写作页「书籍信息」小节头 | `.novel-edit-section-head` | `--sky-blue-dark` | `#fff` | 同上 |
| 阅读器目录折叠头 | `.toc-toggle` | `--sky-blue-dark` | `#fff` | 同上 |
| 阅读器目录分卷名 | `.nreader-toc-part` | `--sky-blue-dark` | `#fff` | bg-soft 12.82:1 |
| 书评区折叠头 | `.nreader-book-comments summary` | `--sky-blue-dark` | `#fff` | 同上 |

**没动的**：

- 大标题（Hero 标题、页面标题 `.page-title`、卡片标题 `.card-title`、文章标题 `.detail-title`、
  小说标题 / 阅读器章节标题）本来就是 `--text-main`，暗色下已是白字，无需改。
- 「更多」链接（`.more-link`）、标签 `.tag`、分类小签、按钮：它们是**链接/标签/控件**不是标题，
  在暗色下保持原来的颜色层（首页分区标题旁那颗「更多」仍是该分类的墨色）。
- 「新建 / 编辑」类小标题（`.edit-profile h3`、`.novel-editor-title` 等）本来没有单独设色，
  继承 `--text-main`，也已经是白字。

## 实现要点（一个坑）

首页分区标题原本是 **组件写死 inline style** `style={{ color: meta.ink }}`，
inline style 的优先级高于任何选择器，暗色覆盖块会被它压住、改了不生效。
所以顺手把这条线改成了项目里通用的做法：**组件只传 CSS 变量、字色由 CSS 决定**

- `Home.tsx`：`style={{ '--sec-ink': meta.ink } as CSSProperties}`
- `index.css`：`.section-title{… color:var(--sec-ink,var(--text-main))}`
  （`--sec-ink` 缺省时落在 `--text-main`，「置顶与收藏」等其他分区标题观感不变）

于是亮色＝分类同色系墨色（与改动前逐像素一致），暗色＝`[data-theme='dark'] .section-title{color:#fff}`。
