# 视觉重构 · 第2f步：字全部用墨色、颜色全部不用墨色

日期：2026-09-14　范围：**只改亮色主题**，暗色主题逐条还原（见文末「暗色还原」）

## 用户要求（原话）

> 还有，字全部用墨色，颜色全部不用墨色

外加一句对「实底 + 白字」这个冲突点的裁定：

> 主按钮不变，关于青蓝色的也不变，只改其他的

## 定下来的配色分工

| 角色 | 用什么 | 不用什么 |
| --- | --- | --- |
| **文字**（正文、标题、标签文字、按钮上的字） | 墨色层：`--text-main` / `--sky-ink` / `--honey-ink` / `--aqua-ink` / `--slate-ink` | 色卡彩色当字色（珊瑚粉/天空蓝/青蓝/蜜金） |
| **颜色**（底色、描边、圆点、图标、光晕、实底） | 色卡色本身：珊瑚粉 `#E89B8A` / 天空蓝 `#5BA8D8` / 蜜金 `#E8C9A0` / 青蓝 `#4A9BB8`（亮色强调色是 `--accent`＝青蓝） | 派生的墨色档（`--sky-fill` `#2E6E92`、`--sky-ink`、`--aqua-ink` 等） |

于是墨色 token 只出现在 `color:` 里，色卡色只出现在 `background` / `border` 里。

## 改了什么

### ① 字全部用墨色（彩色当字色 → 墨字，14 处）

原来用**珊瑚粉当字色**的地方全部改成墨色 `--text-main`（背景里的粉照旧保留，粉只是「颜色」）：

`a:hover`、个人签名 `.profile-signature`、介绍弹窗签名 `.intro-signature`、行内代码 `.markdown-body code`、
图集错误 `.gallery-error`、图集删除 `.gallery-remove`、登录错误 `.auth-error`、评论删除 `.comment-delete`、
回复取消 `.reply-cancel`、评论 @ 前缀 `.comment-name-label em`、bug 状态 `.bug-status`、
网易云音乐卡片链接、附件删除 `.attach-remove`、友链删除 `.friend-op-del`。

分类「随笔」的标签文字同理：`CATEGORY_META.essay.ink` 由 `var(--coral-solid)` 改成 `var(--text-main)`
（粉只留在标签的浅底与分类页头竖条上）。

### ② 颜色不用墨色（墨色当颜色 → 色卡色，25 处）

- **深墨蓝实底 `--sky-fill`（#2E6E92）在亮色下弃用**：凡是「实底 + 白字」的地方改成
  **天空蓝 `#5BA8D8` + 墨字**（4.85:1，比原来的白字压深蓝更好读）：
  文章列表筛选激活态、留言板 tab、评论「回复」hover、bug「标记已处理」hover、关于页历史弹窗按钮 hover、
  小说阅读器页码与阅读设置 pill、友链操作 hover。
  `:root` 里的 `--sky-fill` 定义随之删除（暗色块里保留，供暗色还原引用）。
- **不带字的纯装饰**（滚动条 thumb hover、KaTeX 横向滚动条、空状态放大镜手柄、导航搜索放大镜）
  由墨色改成 `--accent`（青蓝）。
- **用墨色当描边/图标/焦点环的地方** → `--accent`（青蓝）：个人资料与评论区、图集、登录、写作页以外的
  各类 focus 环，图集拖放区 / form dragover 的描边与光晕，关于页 loading 转圈的亮弧，附件项 hover 描边。
- **其他**：搜索提示条左侧竖条 `--honey-ink` → 蜜金 `--honey-gold`；介绍弹窗头像底 `--grad-main`（深蓝墨渐变）
  → `linear-gradient(140deg,var(--accent),var(--accent-deep))`；验证码/about/友链提示条的浅底由 `--aqua-ink` 8~10%
  → 青蓝 `--aqua-blue` 10~12%；分类页头左竖条兜底 `--sky-ink` → `--accent`；分类页头竖条（SectionPage）
  `meta.ink` → `meta.color`；文章列表分类筛选激活态由 `meta.ink` 实底 → `meta.color + '55'` 浅底 + 墨字
  （`CATEGORY_META` 的 `inkOn` 字段随之删除）；留言板 bug 标签的非分类兜底由 `#5C6469` 实底 + 白字
  → 灰蓝浅底 + 墨字。

### ③ 没动的（用户点名）

- **主按钮**：亮色下仍是青蓝 `#4A9BB8` 实底 + 白字（第2c-2 用户定的；`--accent-on` 不变）。
- **已经是青蓝的地方**：第2c/2e 换过去的 `--accent` 一族（Hero、返回顶部、导航激活态、头像底、小说封面、
  写作页装饰蓝、各类 focus 环）一个都没动。
- 收藏星星仍是白字（上一轮用户点名）。

## 暗色还原

文件末尾新增两段「第2f步暗色还原块」：

1. 那批实底在暗色下把字色还原成 `#fff`（暗色的 `--sky-blue` 与 `--sky-fill` 本来就是同一个 `#6ec3ef`，
   只有字色不同）；`.nreader-pill.on` 另还原 `border-color`。
2. 那批「彩色小字」在暗色下仍还原成珊瑚粉 `var(--coral-pink)`（暗色里它们原本就是粉字）。

淡档/描边改走 `--accent` 的地方：暗色下 `--accent` 本来就是天空蓝 `#5BA8D8`，与 `--sky-blue` `#6ec3ef`
同族，观感不变。
