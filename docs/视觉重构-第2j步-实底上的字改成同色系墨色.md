# 视觉重构 · 第2j步：压在色卡实底上的字，改成同色系墨色（不再用黑字）

日期：2026-09-14　范围：**只改亮色主题**，暗色主题原样还原

## 用户要求（原话）

> 你怎么全改成黑色字体了，我让你把字改为同颜色的深色版本

## 问题在哪

第2f步我把一批「深墨蓝实底 #2E6E92 + 白字」改成「天空蓝实底 #5BA8D8 + `--text-main`」，
第2g步分类小签改成实底后，`onFill` 也给了 `--text-main`。
`--text-main` 是 `#2d3436`——**那是黑字，不是同色系墨色**（用户 16:12 已明确「墨字不是黑字而是墨色字」，
第2g 只回退了 14 处珊瑚族的字，这批压在实底上的字漏掉了）。

## 本步改了什么（亮色）

### ① 七处「天空蓝实底 + 黑字」→ 字用天空蓝的同色系墨色 `--sky-ink` #2E6E92

| 位置 | 选择器 |
| --- | --- |
| 评论「回复」hover | `.comment-reply:hover` |
| 留言板选项卡激活态 | `.guestbook-tab.active` |
| Bug「标记已处理」hover | `.bug-toggle:hover` |
| 关于页两个浅底按钮 hover | `.about-head-actions .btn-light:hover`、`.about-history-modal .btn-light:hover` |
| 阅读器目录当前章号 | `.nreader-toc-item.current .nreader-toc-no` |
| 阅读器页码/设置 pill | `.nreader-pill.on` |
| 友链操作 hover | `.friend-op:hover` |

另加分类筛选激活态的**兜底字色**（「全部」那颗没有 `--cat-on`）：`.filter-chip.active{color:var(--cat-on,var(--sky-ink))}`。

### ② 分类小签 `onFill`（`src/types/index.ts`）→ 该分类自己的同色系墨色

| 分类 | 实底 | 字色（本步） | 旧值 |
| --- | --- | --- | --- |
| 读后感 | 天空蓝 `#5BA8D8` | `var(--sky-ink)` #2E6E92 | `var(--text-main)` |
| 随笔 | 珊瑚粉 `#E89B8A` | `var(--coral-ink)` #A8482F | `var(--text-main)` |
| 小说 | 蜜金 `#E8C9A0` | `var(--honey-ink)` #8F6220 | `var(--text-main)` |
| 数学笔记 | 青蓝 `#4A9BB8` | `#fff`（不变） | — |
| 学习分享 | 灰蓝 `#8A8F9A` | `#fff`（不变） | — |

同一套 `--cat-on` 也供文章列表的分类筛选激活态使用，所以那里一并跟着变。

### ③ Bug 反馈的分类标签（`BugFeedback.tsx` 内联样式）

粉底 → `var(--coral-ink)`；无对应分类时的灰蓝浅底 → `var(--slate-ink)`（原来都是黑字）。

## 实测对比度（如实记录，已进 audit 的「已知取舍」）

| 组合 | 本步（同色系墨色） | 上一版（黑字） |
| --- | --- | --- |
| 天空蓝实底 | **2.14:1** | 4.85:1 |
| 珊瑚粉实底 | **2.61:1** | 5.73:1 |
| 蜜金实底 | **3.38:1** | 8.03:1 |

这是「同色系 · 低对比」的取舍，不是算错：用户点名要「同颜色的深色版本」，
而低对比正是「同色系深色压在同一个色的实底上」的必然结果。

**若嫌糊，唯一解法**是把实底从「色卡色实底」换成「该色卡的浅档」（字仍是同色系墨色）：

| 实底档位 | 天空蓝 | 珊瑚粉 | 蜜金 |
| --- | --- | --- | --- |
| 12% | 5.04:1 | 5.29:1 | 5.08:1 |
| 25% | 4.48:1 | 4.80:1 | 4.80:1 |
