# 视觉重构 · 第2k步：分类小签的字，一律改成白色

日期：2026-09-14　范围：**只改亮色主题**，暗色主题原样保留

## 用户要求（原话）

> 在每一个文章左上角小圆圈内的分类文字用白色

「每一个文章左上角小圆圈内的分类文字」＝文章卡片左上角那颗**分类小签**（`.card-cat`）——
圆角胶囊里写着「读后感 / 随笔 / 小说 / 数学笔记 / 学习分享」，底色是该分类的色卡色实底。
文章详情页开头那颗（`.detail-cat`）和文章列表页顶部的分类筛选激活态（`.filter-chip.active`）
跟它是同一套变量，一起跟着变。

## 问题在哪

第2j步按用户「字改为同颜色的深色版本」的要求，把这颗小签的字做成了**该分类自己的同色系墨色**：
天空蓝实底压 `--sky-ink`、珊瑚粉实底压 `--coral-ink`、蜜金实底压 `--honey-ink`。
实测只有 **2.14 / 2.61 / 3.38:1**——「同色系深色压在同一个色的实底上」必然低对比，看上去发糊。

## 实测对比度（如实记录，已进 audit 的「已知取舍」）

| 组合 | 本步（白字） | 第2j步（同色系墨字） |
| --- | --- | --- |
| 天空蓝实底 | **2.61:1** | 2.14:1 |
| 珊瑚粉实底 | **2.21:1** | 2.61:1 |
| 蜜金实底 | **1.58:1** | 3.38:1 |
| 青蓝实底 | 3.15:1 | 3.15:1 |
| 灰蓝实底 | 3.24:1 | 3.24:1 |

这是「浅色色卡实底 + 白字」的必然结果：色卡色本身是浅的（蜜金最浅），压白字对比度就低。
**想拉回 4.5:1 只有一条路**——把实底从「色卡色实底」换成「该色卡的 12% 浅档」，
那时字反而要用同色系墨色（天空蓝 5.04:1 / 珊瑚粉 5.29:1 / 蜜金 5.08:1，数据见第2j步文档）。
用户第2j步明确说过「实底不要自作主张改」，所以本步**只改字色、实底不动**，等他点名。

## 没动的地方（等他点名再改）

1. **暗色主题**：暗色下小签是「13% 该分类色淡底 + `--cat-ink` 同色系墨字」，
   由 `index.css` 末尾的「第2g步暗色还原块」管（那里的 `--cat-fg` 覆盖了 `onFill`），本步一个字没碰。
2. **文章列表筛选框里那颗「全部」**：它是筛选按钮、不是分类小签，亮色下仍是
   `.filter-chip.active{color:var(--cat-on,var(--sky-ink))}` 的兜底墨字。
3. **Bug 反馈页的分类标签**（浅色粉底/灰蓝浅底 + 珊瑚墨字/灰蓝墨字）：底色是浅档不是实底，未动。
4. **主按钮 / 收藏星星 / 数学笔记·学习分享小签**：本来就是白字，无需改。
