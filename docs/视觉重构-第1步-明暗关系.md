## 这一步解决什么

站点「丑」的第一来源不是配色，而是**亮色主题把高亮度品牌色当底色、再往上压白字**。白字压蜜金的对比度只有 1.58:1，正文可读线是 4.5:1——整站因此像蒙了一层雾。

核心改动：**品牌色降为装饰色，新增一套墨色（ink）承载文字，新增一组实底色（fill）承载白字。**

| 用途 | 用什么 |
|---|---|
| 浅底、圆点、描边、装饰 | `--sky-blue` `--coral-pink` `--honey-gold`（原色卡，不变） |
| 亮底上的文字与图标 | `--sky-ink` `--coral-ink` `--honey-ink` `--slate-ink` |
| 需要压白字的底色 | `--sky-fill` `--coral-fill` `--grad-main` |

色值及其对比度（白底实测）：

| token | 色值 | 对比度 |
|---|---|---|
| `--sky-ink` / `--sky-fill` / `--sky-blue-dark` | `#2E6E92` | 5.58:1（原 `#3a86b8` 仅 3.98） |
| `--coral-ink` / `--coral-fill` | `#A8482F` | 5.78:1（原直接用 `#E89B8A` 仅 2.21） |
| `--honey-ink` | `#8F6220` | 5.34:1（原蜜金 `#E8C9A0` 仅 1.58） |
| `--slate-ink` | `#5C6469` | 6.03:1 |
| `--text-secondary` | `#5C6469` | 5.75:1（原 `#7b8085` 仅 3.80） |
| `--grad-main`（主渐变） | `#35769B → #2A6386` | 4.98 ~ 6.51:1 |

## 具体改了什么

1. **首页 Hero**：六色动画渐变 + 白字 + 文字阴影 → 极浅天空蓝→蜜金氛围底 + 墨色文字。主按钮改实心深蓝，次按钮改浅底描边。
2. **分类页头 / 小说书架页头**：分类色满色渐变 + 白字 → 该分类色 12% 极浅底 + 墨色标题 + 左侧 4px 分类色竖条（保留「一眼看出是哪个分类」）。
3. **按钮族**：主按钮用达标深渐变；暖色按钮改**墨字压暖色底**（保留蜜金/珊瑚身份，8.03 / 5.73:1）；危险按钮加深；`btn-light` / `btn-light-outline` 从「白字白边」改为「浅底深字」——顺带修好了写作页、小说编辑器里原本几乎看不见的次级按钮。
4. **分类标签 / 状态徽章**：文字色从品牌色改为同色系墨色（`CATEGORY_META[].ink` / `NOVEL_STATUS_META[].ink`）。文章列表的分类筛选激活态同样改用 ink 底色。
5. **全局机械替换**（73 处文字色 + 27 处底色）：`color:var(--sky-blue)` → `--sky-ink`，`background:var(--sky-blue)` → `--sky-fill`，珊瑚色同理。
6. **搜索提示条**：蜜金→珊瑚渐变 + 白字 → 浅蜜金底 + 墨字 + 左侧蜜金竖条。
7. **小说封面占位渐变** `#2F6B4F→#4A9BB8` 的终点改为 `#2A6577`（白字从 3.15 → 6.51:1）。
8. `::selection`、置顶角标、行内代码等零散处同步修正。

## 明确没做什么（留给后续步骤）

- **暗色主题零改动**：新 token 在 `[data-theme='dark']` 里全部映射回原来的亮色值。
  （注：暗色主题同样存在「白字压亮蓝激活态按钮」的问题，约 25 处，本次按范围未动。）
- **装饰没收敛**：13 处渐变、44 处彩色 rgba 阴影、34 处 hover 位移、emoji 图标 —— 属于第 2 步「砍装饰」。
- **尺度系统没动**：font-size 220 处 48 种取值、padding 97 种、border-radius 19 种 —— 属于第 3 步「字阶与间距阶」。
