# 视觉重构 · 第2g步：墨字＝同色系墨色 + 分类小签改成实底

日期：2026-09-14　范围：**只改亮色主题**，暗色主题原样还原

## 用户要求（原话）

> 1，墨字不是黑字而是墨色字，2，关于读后感全部用天蓝色

追问后用户选定：

- 墨色字 → **各用同色系的墨色**；随笔这类粉色族的字 = **深珊瑚 `#A8482F`**（只给字用）
- 「读后感全部用天蓝色」→ **卡片上的「读后感」分类小签：底色用天空蓝实底**（原来是 13% 淡蓝底），随笔那侧同理

## ① 墨字＝同色系墨色（回退第2f步的「黑字」）

第2f步我把原来用珊瑚粉当字色的 14 处改成了 `--text-main`（`#2d3436`，那是**黑字**）。
本步新增只给文字用的 token `--coral-ink`（亮色 `#A8482F` / 暗色 `#f0a395`），把这 14 处改回去：

`a:hover`、个人签名、介绍签名、行内代码、图集错误、图集删除、登录错误、评论删除、回复取消、
评论 @ 前缀、bug 状态、网易云音乐卡片链接、附件删除、友链删除。

- 它**只出现在 `color:` 里**：底色/描边/面一律还是色卡珊瑚粉（第2d 就是因为拿它当面/底才被否的）。
- 对比度：珊瑚墨色 on 白 5.78:1、on 珊瑚15%底 5.18:1 ✓（比第2f 的黑字更好读也更贴主题）。
- 分类「随笔」的 `ink` 也改回 `var(--coral-ink)`（首页分区标题、「更多」链接、小签文字在暗色下的字色都用它）。
- 第2f 那段「字用墨色」的暗色还原块**删掉**了——现在暗色由 `--coral-ink` 的暗色值自己搞定（= `#f0a395`，与改动前一致）。

## ② 分类小签改成该分类色卡色实底

`.card-cat`（卡片右上角小签）与 `.detail-cat`（详情页分类签）在亮色下由「13% 淡底 + 同色系墨色字」
改成**「该分类色卡色实底 + 能看清的字色」**：

| 分类 | 实底色（色卡色本身） | 字色 | 实测对比度 |
| --- | --- | --- | --- |
| 读后感 | 天空蓝 `#5BA8D8` | 墨字 `--text-main` | 4.85:1 |
| 随笔 | 珊瑚粉 `#E89B8A` | 墨字 | 5.73:1 |
| 小说 | 蜜金 `#E8C9A0` | 墨字 | 8.03:1 |
| 数学笔记 | 青蓝 `#4A9BB8` | 白字（墨字只有 2.07:1） | 3.15:1 |
| 学习分享 | 灰蓝 `#8A8F9A` | 白字（墨字只有 3.88:1） | 3.24:1 |

- 「全部文章」页的分类筛选激活态同口径：`background: var(--cat-color)`、字色 `--cat-on`（「全部」那颗仍是天空蓝实底 + 墨字）。
- 实现方式：组件只传 CSS 变量（`--cat-color` / `--cat-ink` / `--cat-on`），底色与字色在 CSS 里定，
  这样暗色可以用一段还原块改回「13% 淡底 + 同色系墨色字」，不必在 JS 里判断主题。
- **暗色还原**：新增一小段「第2g步暗色还原块」，把 `.card-cat` / `.detail-cat` 还原成
  `color-mix(in srgb,var(--cat-color) 13%,transparent)` + `var(--cat-ink)`，筛选激活态还原成
  `var(--cat-color,var(--sky-fill))` + `var(--cat-ink,#fff)` —— 与改动前一致。
