# 视觉重构 · 第2e步：收藏星星用白色 + 写作页的蓝色改成亮色强调色（青蓝）

日期：2026-09-14　范围：**只改亮色主题**，暗色主题逐条还原（见文末「暗色还原」）

## 用户要求（原话）

> 两件事情，星星仍然用白色，2写作页的蓝色没改

## ① 收藏星星仍然用白色

第 2d 步把珊瑚粉一族改成「粉底 + 墨字」时，顺手把**收藏星星（★／☆）**的字色也换成了墨字。
用户点名要它保持白色，已还原：

- `.fav-btn.fav-on`（文章卡片右上角的收藏星）→ `background:var(--coral-pink); color:#fff`
- `.meta-btn.meta-fav-on`（详情页操作条里的收藏）→ 同上

白字压珊瑚粉 = 2.21:1，比墨字（5.73:1）低，但这是**用户点名要的**，且暗色主题今天就是这个样子，
所以审计脚本里如实标注为「已知取舍」。想提上去就把它换成 `var(--coral-on)`（墨字）。

## ② 写作页的蓝色改成亮色强调色（青蓝）

第 2c 步把亮色主题的强调色换成色卡青蓝 `#4A9BB8`（`--accent`），但**写作页漏改了**：
这一页的实底、浅底、描边、光晕、焦点环还都引用 `--sky-blue`（天空蓝 `#5BA8D8`）
和 `--sky-fill` / `--sky-ink`（深蓝 `#2E6E92`），整页看上去还是旧的蓝色。

本次把写作页**装饰性蓝**全部归到强调色一族（共 41 处改动）：

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 「写普通文章 / 写小说」切换的激活态 | 深蓝实底 `--sky-fill` + 白字 | 青蓝实底 `--accent` + `--accent-on` |
| 小说「新建 / 编辑」切换的激活态 | 同上 | 同上 |
| 浅底按钮（`btn-light`：上传封面 / 新增章节 / 导入 txt 分章等）hover | 深蓝实底 + 白字 | 青蓝实底 + `--accent-on` |
| 同上一族的常态底色 / 描边 | `--sky-blue` 9% / 45% | `--accent` 同比例 |
| 编辑器、输入框、标题框的焦点描边 + 光晕 | 深蓝描边 + 天空蓝光晕 | 青蓝描边 `--accent` + 青色光晕 |
| 「书籍信息 / 章节」分节线、章节列表项与其 hover/当前项、章节序号圆点、工具小按钮 | 天空蓝浅档 | 青蓝浅档 |
| 出版提示条、书籍提示条、媒体拖放区、附件预览项、工具栏按钮描边 | 天空蓝浅档 | 青蓝浅档 |

**没动的**：写作页上的**文字色**。`--sky-ink`（#2E6E92）与 `--sky-blue-dark`（链接/标题/小节标题/
当前标签文字）是全站统一的文字墨色层，不属于「装饰性蓝」，按第2c步的口径保持原样。

## 暗色还原

暗色主题要求原样不变：

- 那几个**实底**（两种模式切换的激活态、浅底按钮 hover）在文件末尾新增的
  「第2e步暗色还原块」里被还原成 `background:var(--sky-fill); color:#fff`（= 改动前的天空蓝实底 + 白字）。
- 淡档（8%~45% 的浅底/描边/光晕）走 `var(--accent)`：它在暗色下本来就是天空蓝 `#5BA8D8`，
  与原来的 `--sky-blue` `#6ec3ef` 同族，观感不变。
