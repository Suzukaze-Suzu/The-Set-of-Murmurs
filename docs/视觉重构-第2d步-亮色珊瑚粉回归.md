# 视觉重构 · 第2d步：亮色下「珊瑚粉」一族的颜色改回色卡本身

日期：2026-09-14　范围：**只改亮色主题**，暗色主题一个像素不变

## 用户要求（原话）

> 把亮色情况下你偷偷改掉的橙色改为凉风凉四色中的粉色

## 问题：橙色是我自己派生的中间色号

「视觉重构第 1 步」（commit `617b1d1`）为了修亮底可读性，我给珊瑚粉派生了一个**墨色档
`--coral-ink` / `--coral-fill` = `#A8482F`**（一个砖橙色），并把全站原本用 `var(--coral-pink)`
`#E89B8A` 的 **26 处**亮色元素统统换成了它：

- 收藏按钮激活态、点赞收藏条激活态（粉 → 橙实底 + 白字）
- 删除按钮（`btn-danger`：粉渐变 → 橙渐变 `#A8482F → #8F3A24`）
- 链接 hover、个人签名、行内代码、错误提示、各类小控件的 ×／删除／取消
- 分类标签（`CATEGORY_META.essay.ink`）、留言板 bug 分类标签（写死的 `#A8482F`）

`#A8482F` 不在「主题灵感」的四色里，是**为了「更好看/更好读」自造的中间色号**，
违反了配色铁律（「使用颜色全部都是我给你提供的凉风凉主题色」「不要变色号」）。这一步把它清掉。

## 改法：珊瑚粉只当「面」，字一律墨色

| 角色 | 改前（亮色） | 改后（亮色） |
| --- | --- | --- |
| 珊瑚一族的字色 / 底色 / 描边 / 圆点 / 光晕 | `#A8482F`（自造砖橙） | `#E89B8A` 色卡珊瑚粉本身 |
| 压在珊瑚粉实底上的字（收藏、删除、各类 hover 底色） | 白字（2.21:1，会糊） | 墨字 `--coral-on = var(--text-main)`（5.73:1） |
| 分类「随笔」标签 / 留言板 bug 标签的实底 | `#A8482F` + 白字 | 珊瑚粉 + 墨字（5.73:1） |
| `.btn-danger` 删除按钮 | 橙渐变 `#A8482F→#8F3A24` | 还原成粉渐变 `#E89B8A→#e07a63` + 墨字 |

token 层面的落地：

- `--coral-ink` / `--coral-fill` **两个 token 取消**（它们只在亮色才有意义），全站 26 处改写成 `var(--coral-pink)`。
- 新增 `--coral-solid`：亮色 `#E89B8A` / 暗色 `#A8482F`；新增 `--coral-on`：亮色墨字 / 暗色 `#fff`。
  分类标签、bug 标签走这两个变量，于是**暗色主题拿到的仍是改动前的原值**。
- `CATEGORY_META` 新增 `inkOn` 字段（压在 ink 实底上的字色），随笔那条用 `var(--coral-on)`。

## 暗色主题为什么没变

暗色块里 `--coral-pink` / `--coral-fill` / `--coral-ink` 本来就都是 `#f0a395`（同一个值），
所以「把两处 token 引用改成 `--coral-pink`」对暗色是恒等变换；`--coral-solid` / `--coral-on`
在暗色块里被显式定义成改动前的 `#A8482F` / `#fff`。实测产物：暗色主题仍是
`#f0a395` 字色 + `#A8482F` 实底 + 白字，与改动前逐条一致。
