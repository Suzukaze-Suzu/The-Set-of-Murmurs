# 视觉重构 · 第2l步：暗色下分类小签的字，用「亮色版的凉风凉色卡色」

日期：2026-09-14　范围：**只改暗色主题**，亮色主题一个字没动

## 用户要求（原话）

> 让暗色下的这个区域的文字全部变成亮色的凉风凉四色

「这个区域」＝上一步（第2k步）刚讨论的那颗**分类小签**——文章卡片左上角圆角小签
（`.card-cat`）与文章详情页开头那颗（`.detail-cat`），两者共用 `--cat-fg` 变量。
「亮色的凉风凉四色」＝**色卡色本身那一档**（天空蓝 `#5BA8D8` / 蜜金 `#E8C9A0` /
珊瑚粉 `#E89B8A` / 青蓝 `#4A9BB8`，学习分享用灰蓝 `#8A8F9A`），而不是同色系的深色墨字。

## 问题在哪

第2k步只改了亮色（白字）。暗色下小签走的是第2g步的「13% 该分类色淡底 + `--cat-ink` 字」，
而 `CATEGORY_META.ink` 里有四类是**写死的深色值**，不会随主题变亮：

| 分类 | 暗色下的字色（改前） | 压在 13% 淡底上 |
| --- | --- | --- |
| 读后感 | `#2E6E92`（写死深蓝） | **2.10:1** |
| 随笔 | `var(--coral-ink)` → 暗色 `#f0a395` | 5.73:1 |
| 小说 | `#8F6220`（写死深金） | **2.03:1** |
| 数学笔记 | `#2A6577`（写死深青） | **1.86:1** |
| 学习分享 | `#5C6469`（写死深灰） | **2.03:1** |

四类基本看不见——这就是他说的「暗色下这个区域」的问题。

## 本步改了什么（暗色）

在 `src/index.css` **末尾追加**一段暗色覆盖块（和第2c/2e/2g 步同一个手法：
靠后的同优先级规则覆盖前面的），把字色从同色系墨色换成该分类的色卡色本身：

```css
[data-theme='dark'] .card-cat,
[data-theme='dark'] .detail-cat{--cat-fg:var(--cat-color)}
```

只改「字」。底仍是第2g步那条「13% 该分类色淡底」（`--cat-chip-bg` 没动），
实底 / 描边 / 尺寸 / 布局一个字没碰；也不需要动任何组件（`--cat-color` 本来就传下去了）。

## 实测对比度（13% 淡底 = `color-mix(色卡色 13%, transparent)` 压在该分类卡片 `#1e2937` 上）

| 分类 | 本步（亮色版色卡色） | 改前（同色系墨字） |
| --- | --- | --- |
| 读后感 天空蓝 | **4.49:1** | 2.10:1 |
| 随笔 珊瑚粉 | **5.23:1** | 5.73:1 |
| 小说 蜜金 | **6.84:1** | 2.03:1 |
| 数学笔记 青蓝 | 3.85:1 | 1.86:1 |
| 学习分享 灰蓝 | 3.77:1 | 2.03:1 |

「天空蓝 4.49 / 青蓝 3.85 / 灰蓝 3.77」差一点点到 4.5:1——因为青蓝、灰蓝本身是中调色、
天空蓝也偏浅，压在 13% 淡底上到不了；已如实记进 audit 的「已知取舍」（不阻断）。
**这五条都比改前好，其中三条是成倍改善。**

## 没动的地方（等他点名再改）

1. **亮色主题**：第2k步的白字保持不变（本步是纯暗色覆盖块）。
2. **文章列表的筛选激活态 `.filter-chip.active`**：暗色下它是**色卡色实底**，
   把字改成同色亮字会直接看不见——要一起改就必须连底一起换成淡档，属于「改实底」，
   按他第2j步定的规矩（实底不要自作主张改）留着没动。
3. **筛选框里那颗「全部」**：暗色下是 `--sky-fill` 深底 + 白字，本来就不是分类文字。
4. **分区标题（第2h步白字）、正文小标题**：他第2h步点名要白色，本步没碰。
