# 呓语集 🎈

一个以「凉风凉」为主题的活泼个人博客，用于记录 **动漫**、**随笔**、**读后感**、**数学笔记** 与 **学习分享**。

## ✨ 功能特性

- 📝 **写作**：内置 Markdown + LaTeX 编辑器，支持预览
- 📐 **数学公式**：KaTeX 渲染，支持行内 `$...$` 与块级 `$$...$$`
- 📂 **导入导出**：支持导入 `.md` / `.tex` 文件，也支持导出
- 🎬 **五大分类**：动漫、随笔、读后感、数学笔记、学习分享
- 🏷️ **标签系统** + ⭐ **收藏/置顶**
- 🔍 **全文搜索**
- 📖 **内置留言板** 与文章评论区
- 👤 **个人资料页**：可上传头像、修改昵称/签名/介绍
- 🌓 **亮/暗主题切换**
- 🎨 配色灵感来自凉风凉（天空蓝 / 蜜金 / 珊瑚粉）

## 🚀 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173

## 📦 构建部署

```bash
npm run build
```

构建产物在 `dist/` 文件夹。由于使用 HashRouter，可直接部署到：
- GitHub Pages
- Vercel
- Netlify

## 🔒 数据存储

文章、评论、留言、个人资料均存储在浏览器的 **localStorage** 中，无需后端服务器，数据保存在每位访问者自己的浏览器里。
