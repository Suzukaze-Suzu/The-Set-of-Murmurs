# 呓语集 🎈
这是来自vibe coding的杰作，由deepseek提供支持。

一个以「凉风凉」为主题的活泼个人博客。
## ✨ 功能特性

- 📝 **写作**：内置 Markdown + LaTeX 编辑器，支持预览
- 📐 **数学公式**：KaTeX 渲染，支持行内 `$...$` 与块级 `$$...$$`
- 📂 **导入导出**：支持导入 `.md` / `.tex` 文件，也支持导出
- 🎬 **五大分类**：动漫、随笔、读后感、数学笔记、学习分享
- 🏷️ **标签系统** + ⭐ **收藏/置顶**
- 🔍 **全文搜索**
- 📖 **内置留言板** 与文章评论区
- 👤 **个人资料页**：可上传头像、修改昵称/签名/介绍
- 🌓 **亮/暗主题切换**
- 🎨 配色灵感来自凉风凉（天空蓝 / 蜜金 / 珊瑚粉）

## 🚀 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173

## 📦 构建部署

```bash
npm run build
```

构建产物在 `dist/` 文件夹。使用 BrowserRouter，页面地址是真实的 `/article/xxx` 这类路径，因此**必须**给服务器配一条 SPA 兜底 rewrite（把非静态资源请求都指向 `index.html`）：Vercel 见 `vercel.json`，Netlify 见 `netlify.toml`。可部署到：
- Vercel
- Netlify
- 任意支持 SPA 兜底的静态托管（GitHub Pages 需自行处理 404.html 兜底）

## 🔒 数据存储

文章、评论、留言、个人资料均存储在浏览器的 **localStorage** 中，无需后端服务器，数据保存在每位访问者自己的浏览器里。
